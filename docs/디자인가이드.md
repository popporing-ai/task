# 디자인 가이드

## 디자인 레퍼런스: Taskworld 스타일
- 다크 사이드바 + 밝은 메인 영역의 명확한 대비
- 카드 기반 칸반, 컬럼별 상태 색상 보더

- 분류별 색상 도트로 빠른 식별
