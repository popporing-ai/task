# 화면 정의서

## 전체 레이아웃 구조

```
┌─────────────┬──────────────────────────────────────────┐
│             │  Topbar (제목 + 액션버튼)                │
│  Sidebar    ├──────────────────────────────────────────┤
│  (200px)    │                                          │
│             │  Content Area                            │
│             │                                          │
└─────────────┴──────────────────────────────────────────┘
```

- Sidebar: 고정 너비 200px, 스크롤 시 고정
- Main 영역: 나머지 너비, 세로 스크롤 가능
- Topbar: sticky, 페이지 제목 + 주요 액션 버튼

- 섹션 레이블: 대문자, 11px, 회색

## 3. 업무 현황 (칸반 보드)

### 상단
- 필터 바 (분류별 / 담당자별 토글 버튼)
- 우측: "+ 업무 추가" 버튼

### 칸반 4열 레이아웃
```
┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐
│  할 일   │ │ 진행 중  │ │   완료   │ │  미진행  │
│   (5)    │ │   (3)    │ │   (7)    │ │   (2)    │
├──────────┤ ├──────────┤ ├──────────┤ ├──────────┤
│ [카드]   │ │ [카드]   │ │ [카드]   │ │ [카드]   │
│ 업무명   │ │ 업무명   │ │ 업무명   │ │ 업무명   │
│ [소개자료]│ │ [홈페이지]│ │ [전시회] │ │ [PR]    │
│ 구지향 ● │ │ 남병진 ● │ │ 안정진 ● │ │ 김모은 ● │
│ D-3 🔴  │ │ D-7      │ │ 3/15 완료│ │ D+2 🔴  │
│          │ │          │ │          │ │          │
│ [카드]   │ │          │ │ [카드]   │ │          │
└──────────┘ └──────────┘ └──────────┘ └──────────┘
```

### 업무 카드 상세
```
┌─────────────────────────────┐
│ [소개자료] [홈페이지]        │  ← 카테고리 태그
│ Remote 소개자료 업데이트     │  ← 업무명 (최대 2줄)
│ ● 구지향          D-3 🔴   │  ← 담당자 + 마감일
└─────────────────────────────┘
```
- 호버 시 우상단에 수정(✏) / 삭제(✕) 아이콘 나타남
- 드래그 중에는 카드 반투명 + 그림자

┌─────────────────────────────┐

## 4. 연간 타임라인

### 레이아웃
```
필터: [전체] [전시회] [네이버광고] [홈페이지] [PR] [브랜딩]

         1월  2월  3월  4월  5월  6월  7월  8월  9월 10월 11월 12월
네이버광고 ████ ████ ████ [현재]
홈페이지  ████ ████ ████ [현재] ████
전시회    [★]      [★]
소개자료  ████ ████ ████ [현재]
PR        ████ ████ ████ [현재] ████ ████
```

- 현재 월: 파란 테두리 강조
- 셀 클릭 → 해당 업무 상세 툴팁 표시
- 행 우측에 "+ 추가" 버튼 (hover 시 나타남)

### 항목 추가 폼 (모달)
- 분류 / 업무명 / 시작 월 / 종료 월 / 상태 / 메모

## 8. 변경 이력

### 상단 필터 + 버튼
```
대상: [전체▼]  작업자: [전체▼]  기간: [2026-03-01] ~ [2026-04-01]
                                              [CSV 내보내기]
```

### 이력 테이블
```
┌──────────────────┬──────────┬────────┬──────────────┬───────────────────────┬──────┐
│ 변경일시         │ 작업자   │ 유형   │ 대상         │ 변경 내용             │ 상세 │
├──────────────────┼──────────┼────────┼──────────────┼───────────────────────┼──────┤
│ 2026-04-01 14:23 │ ● 구지향 │[수정]  │ 업무 현황    │ 상태: 할 일 → 진행 중 │ 보기 │
│ 2026-04-01 13:11 │ ● 남병진 │[생성]  │ 콘텐츠캘린더 │ "반도체 클린룸 AR..." │ 보기 │
│ 2026-03-31 17:05 │ ● 안정진 │[삭제]  │ 업무 현황    │ "VisionX 소개자료..." │ 보기 │
└──────────────────┴──────────┴────────┴──────────────┴───────────────────────┴──────┘
```

- [생성]: 초록 뱃지 / [수정]: 파란 뱃지 / [삭제]: 빨간 뱃지
- "보기" 클릭 → old/new 값 팝오버(JSON 비교)
- 페이지네이션: 50건씩
