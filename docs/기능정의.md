# 기능 정의서

## 0. 인증 (신규)

### 0-1. 회원가입 페이지 (`/task/login.html` → 탭 전환)
- 입력: 이름, 이메일, 비밀번호, 비밀번호 확인
- 이메일 중복 체크 (실시간)
- 가입 완료 즉시 자동 로그인 → 대시보드로 이동
- 별도 승인 프로세스 없음

### 0-2. 로그인 페이지
- 입력: 이메일, 비밀번호
- 성공 시 `task_session` 쿠키 발급 (HttpOnly, 30일)
- 실패 시 "이메일 또는 비밀번호를 확인해주세요" 메시지

### 0-3. 세션 유지
- 모든 페이지 진입 시 `GET /task/api/auth/me` 호출
- 세션 유효 → 정상 진입 / 만료 → login.html로 리다이렉트
- 쿠키 30일 자동 유지 (매 요청 시 만료일 갱신 가능)

### 0-4. 사이드바 하단 — 현재 사용자
- 아바타 + 이름 + "로그아웃" 버튼
- 로그아웃 → 세션 삭제 → login.html로 이동

## 1. 공통 기능

### 1-1. 사이드바 네비게이션
- 메뉴: 대시보드 / 업무 현황 / 연간 타임라인 / 콘텐츠 캘린더 / R&R 현황 / 변경 이력
- 현재 활성 페이지 하이라이트
- 분류 카테고리 색상 도트 목록 (하단)

### 1-2. 공통 CRUD 패턴
- 각 화면에 **+ 추가** 버튼 → 우측 슬라이드 패널
- 항목 호버 시 수정/삭제 버튼 노출
- 삭제 시 확인 다이얼로그
- 저장/수정은 즉시 DB 반영

### 1-3. Audit Log 자동 기록
- 모든 생성/수정/삭제 API 호출 시 audit_logs에 자동 기록
- 별도 설정 필요 없음 (미들웨어 자동 처리)

## 3. 업무 현황 (칸반 보드)

### 칸반 컬럼 4개
| 컬럼 | 상태값 | 의미 |
|------|--------|------|
| 할 일 | todo | 아직 시작 안 함 |
| 진행 중 | in_progress | 현재 작업 중 (파란 좌측 보더) |
| 완료 | done | 마감 처리 (투명도 75%) |
| 미진행 | blocked | 블로킹 또는 기간 초과 (빨간 좌측 보더) |

### 업무 카드 항목
- 카테고리 태그, 업무명, 담당자 아바타+이름, 마감일(D-n)
- D-3 이내: 주황 / 마감 지남: 빨간 / 완료: 초록

### 업무 추가/수정 폼 필드
- 업무명(필수), 분류 카테고리, 업무 상세, 담당자, 마감일, 상태

### 칸반 드래그 앤 드롭
- 카드 드래그 → 다른 컬럼에 드롭 → 상태 자동 변경 + DB 저장 + audit log 기록

## 7. 변경 이력 (신규) ★

### 화면 구성
- 상단 필터: 대상 테이블 / 작업자 / 날짜 범위
- 테이블 목록 표시

### 테이블 컬럼
| 컬럼 | 설명 |
|------|------|
| 변경일시 | KST 기준 YYYY-MM-DD HH:mm |
| 작업자 | 아바타 + 이름 |
| 작업유형 | 생성(초록) / 수정(파란) / 삭제(빨간) 뱃지 |
| 대상 | 테이블명 → 한글 표기 (예: tasks → 업무 현황) |
| 레코드 | 변경된 항목의 제목/이름 |
| 변경 내용 | 주요 변경 필드 요약 (예: "상태: 할 일 → 완료") |
| 상세 | "보기" 클릭 시 old/new JSON 비교 팝오버 |

### 테이블명 한글 매핑
| table_name | 표시 |
|-----------|------|
| tasks | 업무 현황 |
| content_items | 콘텐츠 캘린더 |
| timeline_items | 연간 타임라인 |
| rrr_items | R&R |

### CSV 내보내기
- 상단 우측 "CSV 내보내기" 버튼
- 현재 필터 조건 그대로 적용
- 파일명: `task_audit_YYYYMMDD.csv`
- 인코딩: UTF-8 BOM (엑셀에서 한글 깨짐 방지)

### 필터
- 대상 테이블: 전체 / 업무 현황 / 콘텐츠 캘린더 / 연간 타임라인 / R&R
- 작업자: 전체 / 팀원 선택
- 날짜: 시작일 ~ 종료일 (기본: 최근 30일)
